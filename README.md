# Parent Lotos

Личный кабинет родителя клуба синхронного плавания «Лотос».

## Структура

- `parent_lotos_web/` — фронтенд (React + Vite + MobX-State-Tree + Tailwind) и встроенный API-сервер для auth

## Запуск

```bash
cd parent_lotos_web
npm install
cp .env.example .env
npm run dev
```

Фронтенд: http://localhost:5173  
API: http://localhost:3001
